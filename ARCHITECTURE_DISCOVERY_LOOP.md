# Architecture Discovery Loop

## Purpose

Iteratively collect missing architecture information until the project is fully documented.


## Loop


START


↓

Ask:

"What architecture information is missing?"


↓

Check categories:


- Frontend
- Backend
- Database
- AI models
- Agents
- RAG
- Data pipeline
- Security
- Deployment
- Evaluation


↓

If information missing:


Generate targeted questions.


↓

Collect answers.


↓

Update architecture document.


↓

Run completeness check.



## Completeness Score


Calculate:


Frontend documented = 10%

Backend documented = 10%

AI layer documented = 15%

Agents documented = 15%

Data sources documented = 10%

Database documented = 10%

RAG documented = 10%

Accuracy system documented = 10%

Security documented = 5%

Deployment documented = 5%



If score < 95%:

Continue loop.


If score >=95%:

Generate final architecture report.



END
